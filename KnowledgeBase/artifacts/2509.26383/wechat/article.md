# 知识图谱检索增强生成的新范式：用强化学习打通高效与跨图迁移

> **一句话导读**：KG-R1 把多模块知识图谱检索增强生成流水线压缩成单个大模型智能体，用多轮强化学习直接优化它与知识图谱的交互策略；在小模型主干上取得优异成绩，生成 token 成本显著降低，且只需替换后端图谱就能零样本迁移到未见过的知识图谱。

## 论文速览

现有知识图谱检索增强生成系统高度依赖检索、推理、复核、回答等多模块组成的流水线。每个模块要么依靠针对特定图谱模式的提示词与示例，要么依靠图谱专属的微调，导致系统运行成本高且难以跨领域通用。KG-R1 仅利用一个大语言模型智能体与一个与模式无关的知识图谱查询服务器进行多轮交互，每轮先进行内部推理，再发出 1 跳图查询或给出最终答案，并采用组相对策略优化风格的强化学习端到端训练。在公开数据集上，该方法以较小的 token 消耗取得了强劲的准确率，并展现出优异的零样本跨图谱迁移能力。

## 研究背景与问题

检索增强生成通过外挂知识源降低了大语言模型的幻觉，而知识图谱检索增强生成则把检索源换成了结构化的知识图谱。知识图谱以实体为节点、关系为边，把事实编码成三元组，不仅能缓解模型的知识瓶颈，还能支持复杂的多跳关系推理，并对动态更新的信息保持良好的适应性。正因如此，这类技术在医疗、法律等高风险领域备受关注。

但现有的知识图谱检索增强生成系统几乎都采用模块化工作流，把任务拆成检索、推理、复核、回答四个子任务，每个子任务交由专门的模块处理。这类系统在真实部署中面临效率低下和迁移困难两大瓶颈。一方面，提示式方法需要在每个阶段反复调用大模型，延迟与算力在阶段之间累加，成本高昂；另一方面，无论是提示式还是微调式模块，都绑定在特定知识图谱的模式上，一旦领域漂移或更换图谱，性能就会严重退化。

研究指出，多模块方法在每问生成的 token 数量上明显偏高，而在跨图谱的测试中平均准确率不足。因此，如何构建一个既高效又能跨图迁移的知识图谱交互策略，成为当前亟待解决的核心问题。

## 核心思路

多模块流水线之所以昂贵且不通用，是因为它把怎么查、查什么、查完怎么用拆成了若干个需要单独适配的环节，而这些环节往往绑定了图谱专属的语法和模式。然而，在所有有向知识图谱中都成立且不需要模式知识的操作其实只有一种，那就是沿着一条边做 1 跳遍历。如果把智能体与图谱之间的接口限制为获取出边关系、入边关系、出边实体、入边实体这四种基本动作，接口本身就与图谱模式彻底无关了。

既然接口实现了统一，那么什么时候查、查哪条边、查到什么程度停下来，就应该由一个统一的策略来学习，而不是由人工写死在各个模块里。研究者顺理成章地将问题转化为强化学习任务，把知识图谱当作环境，把查询动作当作行为，把最终答案的正确性当作回报，端到端地训练一个多轮策略。统一策略带来的另一个好处是，模型可以根据问题难度自适应地调整查询次数，从而有效降低整体的 token 消耗。

此外，由于单一回合的最终答案对错提供的信号过于稀疏，研究者设计了两层奖励机制：每轮的格式与查询有效性提供密集的局部信号，而答案正确性与检索命中提供轨迹级信号，再通过组内相对信用分配将全局回报合理摊到每一轮决策中。

## 方法详解

### 整体框架

该方法将任务形式化在知识图谱问答场景中，每条正确答案都对应知识图谱上从问题提及的锚实体出发、沿一系列关系走到答案实体的推理路径。整个系统由一个大语言模型智能体和一个知识图谱查询服务器构成。初始化时，智能体拿到包含通用推理指令、用户问题和服务器说明的提示词。

在每一轮交互中，智能体先进入生成阶段，产出内部推理文本，以及一个图查询动作或最终答案动作。随后进入执行阶段，系统从输出中解析出具体动作。若为查询动作，服务器执行后返回检索到的实体与关系，并追加进对话上下文；若为回答动作，交互终止，系统对答案进行归一化、去重与消解，得到预测答案集。策略直接定义在这些文本序列之上。

### 模式无关的 1 跳动作集

查询服务器对外暴露四个基础动作：获取某个实体的所有出边关系、所有入边关系、通过特定关系相连的尾实体，以及通过特定关系指向的头实体。这个动作集刻意排除了图谱查询语言等需要专门语法知识的复杂接口。

通过正向遍历逐步推进、反向遍历逐步回推，任何多跳问题都可以通过这几个原语组合出来，无需针对不同图谱编写专门的查询语句。这也是即插即用迁移的技术前提。在迁移时，只需将服务器的后端图谱换成新的数据集，用训练好的策略直接评测，无需修改提示词、超参数或进行架构调整。

### 两层奖励与信用分配

为了解决多轮智能体训练中稀疏回报的问题，研究者将奖励拆分为轮级奖励与全局奖励。轮级奖励由格式有效性、知识图谱查询有效性和答案一致性构成；全局奖励则由答案正确性与检索得分共同组成。

在前向探索中，格式检查确保解析器能够正常工作，查询有效性抑制无效操作，而检索得分则提供了一种无需人工路径标注的过程监督，即便最终答案错误，只要检索路径曾经触及真值实体也能获得部分鼓励。

在信用分配方面，系统对每个问题采样多条路径，将轮级奖励与全局奖励加权合成每轮回报，并在同组所有轮次的集合上计算统一的基线来得到相对优势。由于引入了组相对基线，该方法无需额外训练价值网络，就能为多轮决策提供稳定且信息充足的训练信号。

## 实验结果

主干模型采用开源的指令微调模型，训练使用标准的并行解码与强化学习框架。对比基线涵盖了不访问外部知识图谱的纯大模型方法、提示式知识图谱流水线以及基于规划器微调的方法。评测数据集包括多个标准的知识图谱问答基准，指标主要采用单次搜索中真值命中的准确率，同时统计每问生成的 token 数量与端到端延迟。

在域内评测中，该方法在多个主流数据集上取得了很强的准确率，表现逼近甚至超越了参数规模大数倍的多模块流水线方法。在效率方面，该方法每问生成的 token 数量远低于传统的提示式多模块流水线，计算成本大幅下降。同时，系统的单机部署延迟与吞吐量均在合理范围内，具备实际落地的可行性。

在跨图谱的零样本迁移评测中，以某个数据集训练的智能体直接更换后端图谱进行测试，其平均准确率大幅超越纯大模型基线以及传统的知识图谱流水线方法。特别是在模式差异较大的图谱上，增益尤为显著，这充分证明了与模式无关的动作集能够带来良好的跨域泛化鲁棒性。

消融实验进一步验证了各组件的必要性。如果去掉轮级奖励，模型性能出现最大幅度的下跌，说明密集的局部信号是多轮交互收敛的前提；去掉检索奖励虽然对最终准确率影响相对有限，但会导致检索成功率明显下降；而将强化学习算法替换为其他方法则容易引发奖励黑客现象，凸显了可验证奖励兜底机制的重要性。

|---|---|---|---|
| 本文方法 | 优秀 | 较低 | 高 |
| 传统多模块流水线 | 较高 | 极高 | 偏低 |

## 局限与思考

该研究的核心价值在于将工具接口本身作为可迁移性的设计变量，用少量基础原语替代复杂的图谱查询语言，从而让更换后端图谱的即插即用迁移成为可能。同时，结合轮级奖励与组相对优势的强化学习方案，在不增加过多额外训练负担的前提下提供了充足的监督信号。

然而，实验环境大多依赖预先裁剪好的子图，智能体面对的候选空间规模受控且噪声有限。在真实的大规模全量知识图谱部署中，节点的扇出可能极大，上下文容易被淹没，动作空间的有效性也会受到挑战。此外，跨数据集的平均指标可能会掩盖某些特定图谱上的短板，未来的工作需要进一步拓展到更多样化的图谱类型和复杂的交互任务中。

## 总结

KG-R1 成功地将复杂的知识图谱检索增强生成流水线精简为单一的大模型智能体，通过模式无关的 1 跳查询动作和两层奖励的强化学习训练，在保证高准确率的同时大幅降低了 token 消耗，并实现了无需重新训练的即插即用跨图谱迁移。这为未来设计通用、高效的智能体工具调用系统提供了极具价值的参考路径。

## 科学发现范式

- 主要范式：P01 Gap-Driven Reframing
- 次要范式：P02 Cross-Domain Synthesis, P04 Modular Pipeline Composition
- 分类理由：论文针对现有多模块知识图谱检索增强生成流程推理成本高且绑定特定图谱模式的缺口，将任务从固定模块流水线重构为单智能体在知识环境中多轮检索与推理的端到端强化学习优化问题，符合 P01；同时将强化学习与智能体知识图谱检索增强生成结合，并把原多模块流程重构为单智能体与查询服务器的协同，故列 P02、P04 为次要模式。

## 先前工作分析

在知识图谱检索增强生成领域，相关研究通过让大模型在多轮中试探性扩展推理路径，展示了图结构检索对多跳推理的提升，但其每一步都依赖基础模型的反复调用，开销随阶段累积；另有一些工作通过针对特定图谱模式的微调与关系路径生成获得良好可解释性，却把性能牢牢绑定在训练所用的图谱域上。模块化范式进一步凸显了高准确率背后高昂的推理成本。与此同时，相关研究给出了重要洞见，即利用强化学习端到端训练大模型使其在推理中自主发起检索并把结果融入思考，可在单一策略中统一检索与推理；纯强化学习也已被证明能够激发模型的逐步推理能力，而多轮工具调用设定则为依据环境反馈逐步决策提供了基础。当前工作正是将这些先进的单策略强化学习与多轮工具交互思想移植到以知识图谱为环境的设定中，用单一智能体的推理与检索交替取代模块化协调，从而在各项基准上以更小模型和更少消耗同时实现高效率与即插即用迁移。
